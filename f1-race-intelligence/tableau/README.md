# Tableau Deliverables — Formula 1 Race Intelligence

This folder contains the complete, ready-to-run Tableau deliverables:

1. **`f1_race_intelligence.twbx`**: Full Tableau Packaged Workbook containing the connected datasets and pre-configured worksheets, dashboards, and calculations.
2. **`f1_race_intelligence.twb`**: Standard XML Tableau Workbook linking directly to `data/processed/*.csv`.
3. **`calculated_fields.md`**: Complete formulas for `[DNF Count]`, `[Points Cumulative]`, `[Top N Filter]`, `[Pole Position Win Conversion]`, etc.
4. **`dashboard_specification.md`**: Architectural breakdown of the 5 dashboards (F1 Season Overview, Driver Performance, Constructor Analysis, Grand Prix Analysis, Data Storytelling) and the 9 Story Scenes.

## Quick Launch Instructions

- **Option A (Desktop Application):**
  Double click `f1_race_intelligence.twbx` to launch in your installed **Tableau Desktop 2026.3**.
- **Option B (Tableau Public):**
  If sharing online, open in Tableau Desktop and select **Server -> Publish to Tableau Public**.
