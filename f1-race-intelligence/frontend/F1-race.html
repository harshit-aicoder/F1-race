How to Open in Tableau Desktop (Installed on this PC)

  1. Tableau Desktop 2026.3 is installed on this machine at C:\Program Files\Tableau\Tableau 2026.3\bin\tableau.exe.
  2. Double-click the generated tableau/f1_race_intelligence.twbx file or launch Tableau and select File > Open.
  3. All 5 sheets (`circuits`, `race_results`, `championship_standings`, `lap_intelligence`, `qualifying_results`) will unpack automatically from the package.
  4. Use the dynamic [Top N Parameter] slider to alter driver leaderboard depth.
